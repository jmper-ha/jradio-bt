jradio-bt

Bluetooth-модуль для jRadio: приём музыки с телефона и передача на Bluetooth-колонку. Прошивается прямо отсюда, из браузера — ESP-IDF и VS Code не нужны.

Прошить модуль

  1. Подключите модуль (плату ESP32 WROOM-32) к компьютеру USB-кабелем — своим, не через jRadio. Кабель должен быть с данными, а не только зарядный.
  2. Нажмите кнопку и выберите порт модуля в окне браузера.
  3. При первой установке отметьте «стереть всю память». Через минуту модуль перезагрузится с новой прошивкой.

Этот браузер не умеет работать с последовательным портом. Откройте страницу в Chrome или Edge на компьютере — с телефона, из Firefox и Safari прошить нельзя.

Журнал

  


  
Если порт не появляется

  
    
    
  • Драйвер USB-UART. На большинстве плат стоит CP2102 или CH340; Windows иногда не находит драйвер сама:
      CP210x,
      CH340/CH341.
      В диспетчере устройств плата должна значиться как COM-порт.
    • 
    
  • Плата не входит в режим прошивки. Зажмите кнопку BOOT (иногда подписана IO0), коротко нажмите
      RST/EN, отпустите BOOT — и нажмите «Прошить» ещё раз.
    • 
    
  • Порт занят. Закройте монитор порта, Arduino IDE, VS Code с открытым терминалом ESP-IDF.
    • 
    
  • На Linux пользователь должен состоять в группе dialout (или uucp).
    •

    те, что названы в вашем board_options.h:

В прошивке jRadio модуль включается строками BLUETOOTH, BT_UART_TX_GPIO
    и BT_UART_RX_GPIO в board_options.h (TX одной платы идёт в RX другой). Антенны
    двух плат лучше разнести: рядом они мешают друг другу в те секунды, когда модуль ищет колонку. Подробности — в
    описании железа jRadio
    и в README модуля.


  
Что внутри

  
Три файла с этой же страницы: загрузчик, таблица разделов и приложение
    (jradio-bt.bin). Их же можно залить и вручную:
    esptool.py --chip esp32 write_flash 0x1000 bootloader.bin 0x8000 partition-table.bin 0x10000 jradio-bt.bin.
    Собирается автоматически из тега репозитория в ESP-IDF 5.5.5; номер версии вверху страницы — этот тег.

      its own USB, press Прошить ("Flash"), pick the port, allow the erase on a first install. Chrome or Edge

      the CP210x or CH340 driver, or hold BOOT while tapping RST and try again. Wiring to jRadio is in
